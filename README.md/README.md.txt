# Pawcare — Pet Sitting & Dog Walking Template

A premium, conversion-focused website template for modern pet care brands.

## 🚀 Overview
Pawcare is a sleek, production-ready HTML template designed for pet sitting and dog walking businesses. It blends marketing pages with full dashboard experiences, plus premium auth and system pages.

Key highlights:
- Built with clean, semantic HTML
- Organized, scalable CSS system with global variables
- Lightweight JavaScript for smooth interactions
- Dark mode + RTL support out of the box

## ✨ Features
- Responsive design
- Dark mode
- RTL support
- Client + admin dashboards
- Booking-friendly layouts
- Premium auth pages (login + register)
- 404 and coming soon pages
- Modern, accessible UI components

## ⚡ Quick Start
1. Download the template files.
2. Open `pages/index.html` in your browser.
3. Customize text, images, and branding.

## 🎨 Customization
- Colors: Update CSS variables in `assets/css/style.css` under `:root`.
- Fonts: Replace the Google Fonts link in each HTML file.
- Content: Edit text and image sources directly in HTML files.

- RTL toggle (right-to-left layout)

## ❓ FAQ
**Do I need a build tool?**  
No. This is a static HTML template.

**How do I enable dark mode?**  
Use the moon icon in the header.

**Can I connect this to a backend?**  
Yes. Replace form actions and data with your API or server.
