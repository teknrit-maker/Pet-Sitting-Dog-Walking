Introduction

Premium documentation for a premium template.

This guide walks you through setup, customization, and best practices for the Pawcare Pet Sitting & Dog Walking template.

Overview

Built with clean HTML, modular CSS, and lightweight JavaScript. Fully responsive with dark mode and RTL support.

  • Premium home, service, and dashboard layouts
  • Reusable components (cards, buttons, badges)
  • Modern interactions and accessibility-friendly defaults
  • Dark mode and RTL support baked in

Getting Started

Requirements

  • Modern browser (Chrome, Edge, Safari)
  • Local server (optional but recommended)
  • Basic HTML/CSS knowledge

Quick Start

  1. Unzip the template folder
  2. Open `pages/index.html` in a browser
  3. Edit content and replace images

Installation

You can run the template locally or deploy it to any static hosting platform.

Local Preview

Open `pages/index.html` directly, or run a local server for best results.

Deploy

Upload the full folder to Netlify, Vercel, or any static hosting provider.

HTML Structure

Pages use a simple layout: header, main content, and footer. Sections follow a consistent grid and spacing system.

<body>
  <header class="site-header">...</header>
  <main class="page">
    <section class="home-hero">...</section>
  </main>
  <footer class="site-footer">...</footer>
</body>

CSS Structure

Global styles and variables live in `assets/css/style.css`. Dark mode and RTL overrides live in dedicated files.

:root {
  --primary-color: #3a8d8c;
  --secondary-color: #1b2b34;
  --accent-color: #f4c86b;
  --border-radius: 16px;
  --space-1: 8px;
  --space-2: 16px;
}
Tip

Update colors in `:root` to reskin the entire template in minutes.

JavaScript Guide

Core interactions live in `assets/js/main.js`. Dashboard interactions live in `assets/js/dashboard.js`.

const themeToggle = document.getElementById("themeToggle");
const rtlToggle = document.getElementById("rtlToggle");

// Example: toggle a class
document.body.classList.toggle("dark-mode");

Components

Buttons

Use `btn`, `btn-primary`, and `btn-outline` for CTAs and secondary actions.

Cards

Cards like `service-card`, `dashboard-card`, and `sitter-card` are reusable.

Navigation

`site-header`, `nav`, and `dropdown` provide a premium menu system.

Badges

Use pill badges like `status-pill` and `home-hero-pill` for highlights.

Customization

  • Update brand colors in `:root`
  • Swap fonts in the Google Fonts link
  • Edit hero copy and CTA text in HTML
  • Replace images in `assets/images/`

Dashboard Usage

Dashboards include charts and data cards built with HTML + CSS + SVG.

Tip

Update chart values by editing SVG path coordinates and label text.

API / Integration

The template is static by default. Integrate with your backend by wiring form actions to your API endpoints or serverless functions.

  • Connect booking forms to your database
  • Replace static counts with API responses
  • Integrate email tools for newsletters

FAQ

Do I need a build tool?

No. The template runs as plain HTML/CSS/JS.

How do I enable dark mode?

Click the moon icon in the header to toggle dark mode.

Can I translate the site?

Yes. Replace copy in the HTML files and enable RTL if needed.
